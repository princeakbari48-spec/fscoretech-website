About FS Core Tech

Building practical communication software.

FS Core Tech is an independent software development initiative focused on practical communication tools. Its primary project, FS Calling Line, is being developed as a cross-platform calling application.

What we are building

FS Calling Line is currently in development, with Android, Windows, and iOS among its target platforms. The product direction includes incoming and outgoing calling workflows, call history and analytics, and live transcription.

Development & GitHub

Development information and public project resources are available through the FS Core Tech GitHub profile.
