About FS Core Tech

Small, focused, and building in public.

FS Core Tech is a software development identity focused on practical digital products. Its primary current project is FS Calling Line.

What we are building

FS Calling Line is being developed as a cross-platform calling application for Android, iOS, and Windows. The current product direction includes incoming and outgoing calling workflows, call history and analytics, and live transcription.

How this site describes the work

We separate current development goals from released capability. References to features such as transcription, analytics, and cross-platform availability describe the intended product direction unless explicitly stated otherwise.

Open development presence

A GitHub repository link is included across this site so development work can be connected to a public technical profile when the final repository URL is available.
